# 交易决策框架

## 1. 框架定位

本框架用于辅助股票交易学习、观察和复盘，不用于自动交易。

系统可以帮助整理市场事实、归纳板块状态、识别风险和生成复盘报告，但最终交易决策必须由人工完成。

## 2. 决策流程

建议按照以下顺序进行分析：

1. 判断大盘天气。
2. 判断主线板块。
3. 判断板块周期。
4. 识别龙头角色。
5. 检查持仓风险。
6. 形成次日观察计划。
7. 盘后复盘实际表现。

每一步都必须输出证据。

## 3. 大盘天气分析

大盘天气用于判断市场整体环境和仓位态度。

建议分为：

- 晴：指数稳定，成交活跃，赚钱效应强，主线清晰。
- 多云：指数可控，局部机会存在，但分化明显。
- 阴：指数偏弱，赚钱效应下降，题材持续性不足。
- 雨：亏钱效应明显，跌停或大跌增加，需明显控制风险。
- 暴雨：系统性风险释放，情绪极弱，优先防守和观察。

证据维度：

- 指数涨跌幅。
- 两市成交额。
- 上涨家数与下跌家数。
- 涨停数量。
- 跌停数量。
- 连板高度。
- 主线板块持续性。
- 核心个股反馈。

## 4. 板块周期判断

板块周期包括以下阶段：

### 4.1 启动

特征：

- 板块首次明显异动。
- 成交额开始放大。
- 少数核心个股率先上涨。
- 市场关注度刚开始提升。

证据：

- 板块涨幅靠前。
- 板块成交额较前期放大。
- 出现首批涨停或趋势突破个股。

风险：

- 可能是一日游。
- 主线地位尚未确认。

### 4.2 发酵

特征：

- 板块持续走强。
- 参与个股增加。
- 市场开始讨论逻辑。
- 龙头候选逐步清晰。

证据：

- 板块连续多日强于大盘。
- 涨停数量增加。
- 成交额继续放大。
- 核心个股保持强势。

风险：

- 分歧尚未充分检验。
- 后排个股可能波动较大。

### 4.3 主升

特征：

- 主线地位明确。
- 龙头持续上涨。
- 板块内赚钱效应扩散。
- 趋势核心和情绪核心共振。

证据：

- 龙头持续创新高。
- 板块成交额维持高位。
- 多只个股走出趋势或连板。
- 大盘环境没有明显拖累。

风险：

- 追高风险上升。
- 龙头一旦放量滞涨，板块可能进入分歧。

### 4.4 高潮

特征：

- 板块情绪极强。
- 大量个股上涨。
- 后排补涨明显。
- 市场讨论热度很高。

证据：

- 板块涨停数量显著增加。
- 后排个股集中补涨。
- 龙头加速。
- 成交额极度放大。

风险：

- 容易次日强分歧。
- 后排个股容易冲高回落。
- 高潮后不宜盲目扩大风险。

### 4.5 强分歧

特征：

- 板块内部剧烈分化。
- 龙头或高位股出现大幅震荡。
- 后排明显掉队。
- 资金开始切换或观望。

证据：

- 炸板率上升。
- 高位股放量下跌。
- 板块冲高回落。
- 亏钱效应扩散。

风险：

- 如果核心股无法修复，可能进入退潮。
- 持仓需要重点检查。

### 4.6 修复

特征：

- 强分歧后，核心个股重新走强。
- 板块亏钱效应收敛。
- 资金回流主线。
- 龙头重新确认地位。

证据：

- 核心股止跌或反包。
- 板块重新跑赢大盘。
- 成交额恢复。
- 情绪指标改善。

风险：

- 修复可能失败。
- 若缩量修复，持续性需要验证。

### 4.7 退潮观察

特征：

- 板块强度下降。
- 龙头上涨乏力。
- 后排补跌。
- 资金转向其他方向。

证据：

- 板块连续弱于大盘。
- 龙头不再创新高。
- 成交额下降。
- 亏钱效应增加。

风险：

- 可能从观察进入确认退潮。
- 持仓需要降低预期。

### 4.8 退潮确认

特征：

- 龙头破位或持续走弱。
- 板块反弹无力。
- 资金明显撤离。
- 新主线替代旧主线。

证据：

- 核心个股跌破关键位置。
- 板块成交额明显萎缩。
- 涨停数量减少。
- 跌幅榜中出现大量板块个股。

风险：

- 旧主线反抽容易失败。
- 后排个股风险更高。

## 5. 龙头角色分类

### 5.1 趋势核心

定义：

趋势核心是板块中具备中期趋势、资金持续参与、走势稳定的核心个股。

观察维度：

- 是否持续沿均线上行。
- 是否具备稳定成交额。
- 是否反复被资金承接。
- 是否代表板块中长期逻辑。

### 5.2 容量核心

定义：

容量核心是能够承接大资金、成交额高、市值或流动性较大的板块核心。

观察维度：

- 成交额是否位居板块前列。
- 是否能影响板块指数。
- 是否具备机构或大资金参与特征。
- 是否在分歧日仍有承接。

### 5.3 情绪核心

定义：

情绪核心是短线情绪的带动者，通常通过涨停、连板、反包、强势分时等方式影响板块情绪。

观察维度：

- 连板高度。
- 涨停封单。
- 炸板后修复能力。
- 是否带动同板块个股。
- 是否影响短线情绪。

### 5.4 补涨候选

定义：

补涨候选是在主线确认后，因位置较低、属性相近、逻辑相关而可能获得资金挖掘的个股。

观察维度：

- 是否与主线逻辑一致。
- 是否低位启动。
- 是否开始放量。
- 是否有辨识度。
- 是否存在后排风险。

## 6. 持仓风险监控

持仓风险监控不直接给出买卖命令，只提示风险和需要人工确认的问题。

风险等级建议：

- 低风险：走势与计划一致，板块仍在强势周期。
- 中风险：出现分歧或波动，需要观察关键位置。
- 高风险：跌破关键位置、放量下跌或板块退潮。
- 极高风险：原交易逻辑失效，且市场环境明显恶化。

证据维度：

- 个股价格位置。
- 成交量变化。
- 均线状态。
- 板块周期阶段。
- 龙头角色变化。
- 消息面变化。
- 大盘天气变化。

## 9. 结论输出要求

所有结论必须遵守以下格式：

```text
结论：
证据：
风险：
不确定性：
下一步观察：
```

如果证据不足，必须明确写出：

```text
当前证据不足，暂不形成明确结论。
```

禁止输出没有证据支撑的确定性判断。
