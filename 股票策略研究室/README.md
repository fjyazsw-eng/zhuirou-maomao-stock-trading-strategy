# 股票策略研究室（Strategy Lab）

股票策略研究室是一个长期股票市场研究项目，用于沉淀市场数据、板块观察、个股研究、账户风险、六爻假设校准、日报周报和复盘记录。

本项目不是自动荐股软件，不连接券商账户，不执行真实交易，也不替用户做最终交易决定。系统的目标是提高用户的决策质量，而不是替代用户的判断。

## 角色分工

- ChatGPT：首席策略分析师，负责策略分析、逻辑判断、风险控制、六爻解释和条件式方案推演。
- Codex：AI 数据研究员，负责数据抓取、整理、校验、日报生成、文档维护和自动化辅助。
- 用户：最终决策者，负责交易取舍、执行与风险承受。

## 最高原则

1. 任何分析都必须以证据为基础。
2. 以概率思维为核心，不作确定性预测。
3. 以风险控制为底线。
4. 现实市场数据优先。
5. 六爻仅作为宏观方向和阶段结构参考。
6. 系统帮助用户提高决策质量，但不替代用户作最终决策。
7. 必须区分事实、分析、推测和无法验证的信息。
8. 不得为了支持既有判断而选择性使用数据。
9. 所有结论必须说明依据、成立条件和失效条件。
10. 不直接输出“买入、卖出、重仓、梭哈”等命令式结论。

## 固定研究顺序

1. 天气：整体市场。
2. 街区：行业和概念板块。
3. 班长：龙头与核心股票。
4. 店铺：具体个股。
5. 资金：成交额与资金连续性。
6. 六爻：宏观方向辅助校准。
7. 账户：仓位与组合风险。
8. 策略：条件式交易方案。
9. 风控：成立条件与失效条件。
10. 复盘：预测与实际走势对照。

## 目录结构

- `config/`：账户基准、观察池和项目配置。
- `data/raw/`：原始市场数据。
- `data/processed/`：清洗和整理后的数据。
- `reports/daily/`：每日研究报告。
- `reports/weekly/`：每周研究报告。
- `reports/review/`：复盘报告。
- `reports/hexagram/`：六爻现实校准记录。
- `portfolio/`：持仓、组合风险和账户分析材料。
- `prompts/`：固定研究模板和报告模板。
- `scripts/`：后续自动化脚本位置，暂不包含自动交易功能。
- `tests/`：后续数据校验和报告生成测试。
- `docs/`：项目规则、数据来源、研究说明和变更记录。

保留的早期目录：`daily_reports/`、`weekly_reports/`、`market_data/`、`backtest/`、`journal/`。后续优先使用新的标准目录，旧目录不删除，避免丢失历史内容。

## 使用方法

1. 先更新 `config/account_baseline.yaml` 和 `config/watchlist.yaml`。
2. 收集并登记数据来源，更新 `docs/data_sources.md`。
3. 使用 `prompts/daily_research_report_template.md` 生成每日研究报告。
4. 使用 `prompts/weekly_research_report_template.md` 生成每周研究报告。
5. 如果涉及持仓调整，必须使用 `prompts/switching_analysis_template.md` 做横向比较。
6. 如果涉及六爻，必须由用户提供排盘，Codex 只记录和验证，不独立断卦。
7. 所有研究结论必须写明依据、成立条件、失效条件和数据缺失部分。

## 风险边界

- 不提供命令式交易指令。
- 不保证收益，不作确定性预测。
- 不把历史数据冒充实时数据。
- 不伪造无法取得的数据。
- 不为了迎合六爻、市场传闻或既有观点而选择性使用数据。
- 不自动连接券商账户。
- 不执行真实交易。
- 不默认使用全部现金。
