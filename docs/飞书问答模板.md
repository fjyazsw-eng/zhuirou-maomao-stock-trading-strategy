# 飞书问答模板

你在飞书里可以直接按这个格式问：

## 空仓

`问：我现在空仓，资金 5 万，怎么安排？`

## 持仓

`问：我有 002468 1000 股，成本 15.80，怎么处理？`

## 单票

`问：鼎龙股份现在怎么样，能不能低吸？`

## 板块

`问：半导体这两天走弱，是回调还是退潮？`

## 最好带上这几个信息

- 你现在是空仓还是持仓
- 资金多少
- 持仓代码、数量、成本
- 你想看短线还是中线

## 我会怎么回

- 先看大盘天气
- 再看板块强弱
- 再看个股位置和 K 线承接
- 最后给你一句白话结论

## 你可以直接复制的提问

```text
问：我现在空仓，资金 50000，短线想找机会，先看什么？
```

```text
问：我持有 002468，成本 15.80，看看要不要减仓
```
