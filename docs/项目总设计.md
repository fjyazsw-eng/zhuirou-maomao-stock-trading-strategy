# 项目总设计

## 1. 项目定位

“股票AI交易助手”是一个本地 AI 辅助项目，目标是帮助使用者进行股票交易学习、市场观察、交易计划整理和实战复盘。

项目不自动下单，不连接券商交易接口，不替代人工决策。系统输出的内容应作为观察材料、复盘材料和决策辅助，而不是最终交易指令。

## 2. 项目目标

项目未来要逐步支持以下能力：

- 大盘天气分析。
- 板块周期判断。
- 龙头识别。
- 持仓风险监控。
- 半导体、通信设备、券商等重点板块跟踪。
- 每日盘后报告。
- 每周复盘。
- 六爻周度判断与现实市场对照。
- 后续接入行情数据源和本地数据库。

## 3. 第一阶段目标

第一阶段不追求完整自动化，先建立清晰、可复盘、可扩展的基础框架。

第一阶段交付重点：

- 明确项目用途和边界。
- 建立文档体系。
- 建立交易决策框架。
- 建立板块周期判断标准。
- 建立龙头角色分类标准。
- 建立证据输出要求。
- 设计后续文件夹结构。
- 为行情数据源、本地数据库、报告系统预留扩展空间。

## 4. 项目边界

### 4.1 暂时不做自动交易

项目暂时不做以下内容：

- 不自动下单。
- 不自动撤单。
- 不连接券商实盘交易接口。
- 不生成必须执行的交易指令。
- 不承诺收益。
- 不替代人工判断。

### 4.2 输出必须有证据

所有分析结论必须附带证据。没有证据的内容只能标记为“假设”“观察”“待验证”，不能直接写成结论。

证据类型包括：

- 指数涨跌幅。
- 成交额变化。
- 涨停数量。
- 跌停数量。
- 连板高度。
- 板块涨跌幅。
- 板块成交额。
- 核心个股走势。
- 龙头股封单、换手、成交额、分时强度。
- 消息面来源。
- 持仓个股价格、均线、量能、关键位置。
- 历史复盘记录。

## 5. 核心模块规划

### 5.1 大盘天气分析

用于判断市场整体环境。

重点观察：

- 上证指数、深证成指、创业板指、科创板相关指数。
- 两市成交额。
- 上涨家数与下跌家数。
- 涨停、跌停、炸板、连板数据。
- 北向资金或其他资金指标。
- 市场风险偏好。
- 指数与题材是否共振。

输出结果示例：

- 天气：晴、多云、阴、雨、暴雨。
- 风险偏好：高、中、低。
- 适合策略：进攻、试错、低吸、控仓、观望。
- 证据列表。

### 5.2 板块周期判断

用于判断板块或题材当前所处阶段。

周期阶段包括：

- 启动。
- 发酵。
- 主升。
- 高潮。
- 强分歧。
- 修复。
- 退潮观察。
- 退潮确认。

每次判断必须说明：

- 当前阶段。
- 前一阶段。
- 阶段变化依据。
- 核心个股表现。
- 成交额与赚钱效应。
- 风险点。
- 下一交易日观察条件。

### 5.3 龙头识别

用于识别板块内部不同类型的核心个股。

龙头角色包括：

- 趋势核心：以中期趋势、机构资金、持续成交额和稳定上行为主要特征。
- 容量核心：以高成交额、大市值、能承接大资金为主要特征。
- 情绪核心：以涨停、连板、短线情绪带动为主要特征。
- 补涨候选：在主线确认后，可能因低位、同属性、同概念、同逻辑而补涨的个股。

识别龙头时必须输出：

- 所属板块。
- 当前角色。
- 证据。
- 风险。
- 是否需要继续观察。

### 5.4 持仓风险监控

用于辅助检查持仓是否出现风险。

监控维度：

- 个股是否跌破关键位置。
- 是否放量下跌。
- 是否缩量反弹无力。
- 是否跟随板块退潮。
- 是否失去龙头地位。
- 是否出现消息面风险。
- 是否与原交易计划不一致。

输出不应直接命令买卖，而应提示：

- 当前风险等级。
- 风险证据。
- 需要人工确认的问题。
- 可供复盘的观察点。

### 5.5 重点板块跟踪

第一批重点板块：

- 半导体。
- 通信设备。
- 券商。

每个板块建议跟踪：

- 板块指数或代表性指数。
- 板块成交额。
- 板块涨跌幅。
- 核心个股列表。
- 趋势核心。
- 容量核心。
- 情绪核心。
- 补涨候选。
- 当前周期阶段。
- 关键催化事件。

### 5.6 每日盘后报告

每日盘后报告用于记录当天市场事实和初步判断。

建议内容：

- 日期。
- 大盘天气。
- 指数表现。
- 成交额变化。
- 情绪指标。
- 主线板块。
- 重点板块状态。
- 龙头角色变化。
- 持仓风险提示。
- 次日观察重点。
- 证据列表。

### 5.7 每周复盘

每周复盘用于检查一周判断是否有效。

建议内容：

- 本周市场主线。
- 本周大盘天气变化。
- 板块周期变化。
- 龙头表现。
- 持仓表现。
- 判断正确的地方。
- 判断错误的地方。
- 下周重点观察。

### 5.8 六爻周度判断与现实市场对照

该模块用于记录六爻周度判断，并与实际市场表现对照。

注意：

- 六爻内容作为个人研究和复盘材料。
- 不作为单独交易依据。
- 必须与现实市场数据对照。
- 必须记录预测内容、实际结果和偏差原因。

## 7. 后续技术方向

后续可逐步接入：

## 8. 输出规范

所有模块输出建议统一采用以下结构：

```text
结论：
证据：
风险：
不确定性：
下一步观察：
```

如果证据不足，必须写明：

```text
当前证据不足，暂不形成明确结论。
```
