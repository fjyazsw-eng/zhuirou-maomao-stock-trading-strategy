# 飞书接入大白话

## 你要做什么

你只需要在飞书里建一个群机器人，然后把机器人给你的 webhook 地址填到本项目里。

这不是长期扫码登录。扫码最多只是你登录飞书客户端、进群、管理群时用一下。程序真正发送消息靠的是 webhook 地址。

## 第一步：在飞书建一个群

可以新建一个群，比如：

股票AI量化助手

也可以用已有群，但建议先用测试群，避免调试消息打扰别人。

## 第二步：添加自定义机器人

在飞书电脑端打开目标群：

1. 进入群设置。
2. 找到群机器人。
3. 点击添加机器人。
4. 选择自定义机器人。
5. 名字可以填：股票AI助手。
6. 添加后复制 webhook 地址。

webhook 地址一般长这样：

```text
https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx
```

这个地址相当于机器人的“收件地址”，不要发到公开地方。

## 手机端容易点错的地方

如果你在聊天输入框下面看到“飞书机器人助手”“定时消息”“任务”“收集表”等入口，这些不是我们要接的端口。

这些功能更像飞书自带的小工具，只能帮你手动设置定时提醒，不能给本地模型一个稳定的 webhook 地址。

我们要找的是：

```text
群设置 -> 群机器人 -> 添加机器人 -> 自定义机器人
```

如果手机端找不到“自定义机器人”，优先用电脑端飞书操作。电脑端通常更容易找到群机器人和复制 webhook。

## 判断你是不是找对了

找对以后，你一定会看到一个以这个开头的地址：

```text
https://open.feishu.cn/open-apis/bot/v2/hook/
```

如果没有看到这个地址，就还没到正确页面。

## 第三步：安全设置怎么选

第一版建议用最简单方式：

- 先不要开 IP 白名单。
- 可以不开签名，先把通道跑通。
- 跑通后再开启签名校验，把签名密钥也填进配置。

如果你开启了签名校验，需要同时保存两个东西：

- webhook 地址
- 签名密钥

## 第四步：填到项目配置

复制这个文件：

```text
C:\Users\HUAWEI\Documents\股票AI交易助手\config\push_channels.example.json
```

保存为：

```text
C:\Users\HUAWEI\Documents\股票AI交易助手\config\push_channels.json
```

然后把里面的 `webhook_url` 改成你的飞书 webhook。

如果你开了签名校验，把 `secret` 也填上。

示例：

```json
{
  "feishu": {
    "enabled": true,
    "webhook_env": "FEISHU_WEBHOOK",
    "webhook_url": "https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx",
    "secret_env": "FEISHU_SECRET",
    "secret": ""
  }
}
```

## 第五步：测试发送

配置好后，运行飞书测试发送。

如果成功，飞书群里会收到一条：

股票AI量化助手端口测试

## 后续能做什么

第一阶段：

- 每日盘后自动发简报。
- 预警触发时发风险提醒。
- 单票体检结果推送到飞书。

第二阶段：

- 你在飞书里发问题。
- 系统读取问题。
- 调用本地模型分析。
- 把结果回发到飞书。

注意：第二阶段如果要真正做到“飞书里直接问、飞书里直接答”，需要飞书开放平台应用和事件回调，比 webhook 推送复杂。
