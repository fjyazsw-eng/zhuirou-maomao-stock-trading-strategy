# 日常运行流程 MVP

这份文件说明每天怎么使用“股票AI交易助手”。它不是交易指令，也不是自动下单流程，只是把已经完成的模块按固定顺序跑一遍、看一遍、检查一遍。

## 一句话顺序

```text
大盘天气 -> 优势板块 -> 板块周期 -> 个股角色 -> 执行标签 -> 仓位 -> 持仓 -> 账户风险
```

## 盘前或开盘前

先看前一日已经生成的报告，不要因为看到候选股就急着操作。

重点看：

- 大盘天气是不是风险环境。
- 优势板块是否已经高潮、分歧或退潮。
- 候选股是不是核心股，而不是补涨或后排。
- 执行标签是否允许买。
- 账户总仓位是否已经接近上限。
- 自己当天能不能盯盘。

盘前原则：

- 风险环境下不为了买而买。
- 高分股票不等于可以买。
- 板块高潮不追高。
- 板块分歧先等承接。
- 结构性机会只能小仓或观察仓。
- 不能盯盘时自动更保守。

## 盘中

当前系统还没有正式接入实时盘中提醒，所以盘中只能作为人工观察参考。

盘中边界：

- 不自动交易。
- 不自动下单。
- 不接真实交易账户。
- 没有飞书/TG提醒时，不建议执行高波动短线策略。
- 若盘中出现急涨急跌，以执行标签、持仓保护线和账户仓位上限为准，不临时放大风险。

## 盘后

盘后是当前系统最适合运行的时间。

建议流程：

1. 先运行健康检查。
2. 生成或刷新市场总览报告。
3. 生成 HTML 看板。
4. 生成空仓/持仓建议。
5. 生成账户级仓位建议。
6. 检查关键输出文件是否存在。
7. 把简明完成情况交给 GPT/Codex 审查。

## 主要输出文件

- `reports/latest_market_decision_report.md`
- `reports/latest_market_decision_dashboard.html`
- `reports/advice/position_advice_YYYYMMDD.md`
- `reports/advice/account_position_advice_YYYYMMDD.md`
- `reports/workflow/latest_workflow_status.md`

## 每日报告阅读顺序

1. 先看大盘天气：决定进攻、观察还是防守。
2. 再看优势板块：判断是否有主线或结构性机会。
3. 再看板块周期：启动、发酵、高潮、分歧、修复、退潮、结束。
4. 再看个股角色：龙头、容量核心、趋势核心、补涨、后排、弱结构。
5. 再看执行标签：能不能买，等不等，是否保护利润。
6. 再看仓位建议：空仓最多几成，持仓是否减风险。
7. 再看持仓管理：浮盈保护、浮亏止损、逻辑是否破坏。
8. 最后看账户风险：总仓位、单票仓位、板块集中度。

## 操作原则

- 风险控制优先于个股分数。
- 账户总仓位不能突破大盘天气给出的上限。
- 单票仓位不能突破角色和执行标签给出的上限。
- 板块集中度过高时，不继续加同一板块。
- 浮盈要保护，不把利润重新亏回去。
- 浮亏不盲目补仓，先判断逻辑是否破坏。
- 不能盯盘时，不追高波动、补涨和后排。

## 当前限制

- 当前为辅助决策系统，不是实盘自动交易系统。
- 当前账户数据仍以模拟输入为主，不代表真实账户。
- 盘中实时提醒仍是后续模块。
- 2025历史数据和历史概念池仍未完整补齐。
